Project Overview

The Margaret E. Heggan Library's Current Site

Margaret E. Heggan Library serves Washington Township, NJ with books, media, programs, and digital resources. Its website is the gateway for catalog searches, event calendars, and e-services, so it must be intuitive and accessible for all ages.

This redesign aims to streamline navigation, improve accessibility, and provide a consistent, responsive experience across devices.

Key Issues

Accessibility

WebAIM flagged 31 errors and 207 alerts (missing alt text, contrast failures, unlabeled forms), making the site hard to use with assistive tech.

Usability

Overwhelming tabs and scattered content force users to hunt for information which slows task completion and reducing clarity.

The Redesign

We streamlined the navigation into a fixed top bar with clear labels, replaced clutter with hero carousels, and introduced consistent full-width accent bars. Responsive breakpoints ensure every device feels native.

What I Learned

Through this redesign project, I discovered that a library website must prioritize clear navigation to serve a community of alll ages and demographics. By identifying key issues—such as cluttered layouts, and poor information hierarchy I learned the value of using intuitive visual cues like seperation red bars and centered carousels to create a user-friendly experience. Implementing responsive design not only enhances usability across devices but also ensures that critical information like library hours, events, and book catologs are easily accessible for everyone.
